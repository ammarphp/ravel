# Whole-question stage correspondence

This source compiler connects the existing whole-resonance recipe to ordinary generation, analysis, template and inference tasks. It prepares one selected existing stage through the ordinary scientific intake. The ordinary execution and scientific acceptance owners retain their authority. The existing research cycle, blueprint, Host context, retained-study policy and stage supervisor remain the operational route.

## Operative target mapping

A stage can carry a `target_mapping`: a pinned JSON document with `schema_version: 2`, `original_study`, `hypothesis_sha256`, `search_sha256`, `projected_target`, `bindings`, `sources` and `limitations`. Obtain `projected_target` from `ravel.workflow.stage_correspondence.project(spec, base, capture)`. The actual selected adapter validates its whole transitive source population. A mapping must equal that projection; manually asserted schema labels must not replace absent physical fields.

Each closed binding contains `field` and `address`. Generation requires collision energy, model manifest digest and literal `MASS/<PDG>` and `DECAY/<PDG>` addresses for the same particle. A binding to `coupling/<name>/real` or `/imag` compares the named original hypothesis component with a literal card value. Units, vertex conventions, CP, spin, production interpretation and interference meaning remain source premises unless supported independently. Analysis energy comes from its actual metadata; signed interference requires a signed prediction law. Native fit scan mass is not a resonance hypothesis mass.

The scoped registry also reads the actual `svj-recipe`, `mass-width-grid`, `llp-plane-recipe` and `mssm-observable-map` source validators. It retains every supplied document, domain point, cell and missing input of the supplied study. A supplied population is not a generated prediction, fit or exclusion result. Missing physical inputs stay explicit.

## Accepted producer transport

A model-events stage can export a descriptor such as `{"kind":"generated_member","path":"Events/run/sample.hepmc","format":"HepMC2"}`. The path must name the exact intended member already recorded by the producer. A later actual Rivet or Rivet-built task can link it with `{"task_key":"events","from_stage":"generation","export":"events"}`. The selected adapter determines that this slot is an event pathname. Its original beam metadata, event exposure, complete weight roster and observed full-stream census must match the original producer; metadata must not relabel generated populations.

Document links retain the existing `document`, `pointer`, `from_stage`, `export` form. Native model-file slots retain their original `staged_path` and closed file pin; complete cards, regions, construction laws and fit configuration are projected again after transport. Only the original admitted pathname is relocated. Digests, numbers, normalized weights, scientific quantity and deliverables remain bound. No arbitrary task path or guessed workspace file becomes accessible.

## Prospective complete Events commitment

New model-events production writes a versioned `generated-member-commitment.json` for the complete original Events directory. The commitment includes every ordinary file, empty directory, lexical ancestor identity and leaf identity/content, checked before and after hashing. Selected and unselected additions, removals, replacements, symlinks and special files refuse. The native worker and parent adapter recheck it; the common science worker rechecks the complete original config, native result, census, ordinary result and Events commitment after result/report publication. This is finite checkpoint custody, not continuous containment or an ABA-proof sandbox.

Old records are not migrated or retroactively qualified. An explicit `retained_producer: true` model-events stage uses the existing accepted retained-study policy and original immutable execution specification. A specification without a later resonance header is admissible only when exactly equal to the pinned original supplied study. Current accepted review, original source/runtime/card/model/native evidence, output snapshot and prospective complete Events commitment remain mandatory. Superficially matching modified studies and new predecessors missing their recipe header refuse.

## Existing portfolio admission

A blueprint or followup bound portfolio can carry a pinned `stage_correspondence` document; it has `schema_version: 1`, `recipe`, and a complete `stages` list of `{"experiment":...,"stage":...}` rows. Every experiment must identify its exact original operative study and the recipe and all operative dependencies must already be disclosed Host inputs. Missing experiments, source mismatches and unresolved stage blockers refuse before the existing admission. Current context, proposal revision, heldout exposure and adoption rules are unchanged.

No summary substitutes for generation, analysis or inference. Unknown, failed, unreviewed and missing outcomes retain the whole original hypothesis/search denominator. The original research goals, full populations and independent scientific qualification obligations remain open until actual authorized work establishes their results.

Native-likelihood correspondence retains the ordered complete model-file roster,
including every digest and native staged name. Accepted links can relocate identical
files; they must not change a non-card template or its native destination.
