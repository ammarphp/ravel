# Generation-time process observation

The source-bound model-event worker copies the authenticated RAVEL process
observer into the admitted MG5 child. It records generation-time
`ProcessDefinition` properties, reconstructed prospective aliases and the full
observed process roster. Exported command history is a separate diagnostic.

MG5 2.9.27 `PhysicsObject.get` / `Process.get` take one property name; they do not
accept `dict.get` defaults. The native decay-chain property is read with one
argument. `ProcessDefinition.default_setup` supplies it; missing properties fail
rather than silently yielding an empty roster. Shared model objects are excluded,
while process orders, squared/constrained orders, restrictions, polarizations and
nested decay properties are retained. Ordinary intake's decay-chain
syntax remains refused.

A matched observation establishes only the declared external process-identity
scope. Coupling orders are retained, not independently amplitude-certified; event
generation, normalization and numerical/physics validity require their own
ordinary source-bound execution and review. Failed observations and attempt-local
MG5 debug files remain evidence of failed attempts. A repaired observer requires
fresh current source/config/plan binding and ordinary execution approval.
