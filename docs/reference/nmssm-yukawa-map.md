# Finite NMSSM tree Yukawa prediction map

This operation converts a complete, explicitly selected real FlexibleSUSY 2.9.0 NMSSM tree SLHA point into all 81 neutral CP-even Higgs–fermion couplings/channels. It is a finite physical convention compiler and supplied-data prediction, not a spectrum solver or universal UV/EFT matching rule.

Use `ravel model-conventions --request request.json` to inspect the source/equation context. A Graph construction node can request the same context through AgentHost action `nmssm-yukawa-context`; all request, card, equation and accepted-origin inputs must be explicit Graph pins. This tool consumes an ordinary charged call and performs no scientific execution. Execute the prediction through the existing `ravel plan` / `ravel run` scientific-study mode `nmssm-yukawa-map`, with task `{"request": "request.json"}`. Existing CI1, supervisor, complete input snapshot and original actor review apply. The operation admits one attempt, no automatic redo, and delivery-only claim scope `nmssm_tree_yukawa_prediction_delivery`; successful calculation does not authorize physics reuse or parent-goal acceptance.

The schema-1 request has exact keys `schema_version`, `operation: nmssm_tree_yukawa`, `profile: NMSSM-FlexibleSUSY-2.9.0`, `spectrum` and `input_card` file pins `{path, sha256}`, `scale_token`, `validity`, `checks`, and `origin`. `validity` is exactly `{basis: FlexibleSUSY-2.9.0-NMSSM-SLHA2-SVD, cp: real_CP_even, flavour: three_generation_diagonal, order: tree_DRbar_at_explicit_Q, kinematics: on_shell_two_body}`. `checks` explicitly supplies nonnegative string bands `mixing_absolute`, `mass_squared_absolute_GeV2` and `mass_squared_relative`. No universal numerical tolerance is invented. `origin` is either `{kind: supplied_unqualified}` or `{kind: accepted_named_spectrum, run: <existing run>}`. The latter resolves the actual current accepted named-spectrum review, exact returned file, generated result, original card and full censuses; accepted consumption requires that exact review and source binding.

The original card must explicitly select SM output (`FlexibleSUSY[3]=1`), zero pole-mass loop order (`[4]=0`), no forced output (`[12]=0`) and BSM output (`[23]=1`), with `MODSEL[6]=0` and optional `MODSEL[5]=0`. Other input settings, including EWSB/RGE choices, remain supplied and unchanged. The selected map describes a tree Born vertex at the supplied DRbar scale, not how that running point was solved. Higher pole-loop order refuses because NMHMIX otherwise represents physical/pole mixing rather than the selected tree matrix.

Require all nine real addresses in each YD/YU/YE block at the identical lexical Q token, all nine NMHMIX addresses, positive same-Q HMIX[102]/[103], all 12 relevant MASS entries, nonnegative ascending Yukawa singular values and zero off-diagonal entries. Selected imaginary matrices, if present, must be complete and zero. Unrelated blocks, warnings, DECAY records and original lines stay in the result. Exact rational arithmetic checks the full mixing Gram matrix and all nine relations `m_f² = y_f² v_f²/2` against the caller's declared engineering bands. Missing, duplicate, complex, off-diagonal, tachyonic or inconsistent populations refuse without repair or clipping.

Released generated couplings contract as `ZR Y ZL^T = diagonal(y)` in the real SLHA SVD basis. Removing the vertex's global `i`, `gL = gR = -y_f ZH[i,a]/sqrt(2)`, with `a=1` for down quarks/leptons and `a=2` for up quarks. The convention is `i*(gL PL + gR PR)`. Three Higgs states (PDG 25/35/45), three fermion families and all nine ordered generation pairs produce 81 rows; 54 flavour-off-diagonal zeros follow from this declared basis. The singlet gauge component has no direct selected Yukawa term. Existing `ufo_decay.tree_reference` evaluates open on-shell Dirac-pair channels with color 3 for quarks and 1 for leptons. Closed/threshold rows retain `tree_reference: null`, without an off-shell prediction or fabricated zero. Exact prefactors and derivation checks accompany binary64 coefficients/widths; nonfinite, underflowing or collapsed positive channels refuse.

Output `nmssm-yukawa-map.json` retains the complete input census, equations/source pins, every row and validity limits. `compile_map` returns the same reusable supplied-data derivation; `verify_result` recomputes it and refuses numerical edits even if the edited object is self-rehashed. Cards and supplied total DECAY widths are not changed. No branching ratios, total widths, production, loop accuracy, perturbativity, UV matching or EFT running are certified. Native vertex/amplitude equivalence and physical spectrum qualification remain separate.

Primary basis: [FlexibleSUSY 2.9.0 release](https://github.com/FlexibleSUSY/FlexibleSUSY/releases/tag/v2.9.0), commit `64276b57499cba6577940c3fc605b9d4b45b3130`, and [FlexibleSUSY paper](https://arxiv.org/abs/1406.2319). Exact generated Cp, tree-mixing copy, SVD and writer source identities are in `data/spectrum/nmssm-tree-yukawa.json` and the existing named profile. The portable fixture contains six exact FlexibleSUSY sources including its GPL-3.0 COPYING. SARAH model-definition hashes remain source lineage in the existing profile; additional local SARAH copies are private inspection material, excluded from this public fixture because a redistribution grant was not located in the inspected metadata.
