# Manuscript integrity and retained source limits

The manuscript integrity audit covers score verification, specification compliance, reference verification and method-code alignment. Its writer consumes a code audit and search-grounded bibliography correction. RAVEL implements the complete source/citation/method presentation and the actual writer/reviewer/revision joins; it claims no audit efficacy beyond its recorded checks.

Existing scientific_report owns exact supplied numerical slots and complete requested-quantity statuses. Existing task_completion/research_protocol/scientific_judgment own specification/parent/actual study/review contracts. report_integrity adds the whole text census and actual stage/code/result/bibliography presentation. manuscript_production adds an actual accounted Graph writer from original research context, material feedback revision, reproducible source and ordinary build. manuscript_build adds real supervised rendering, recorder source observations and physical page boundaries. Full independent integrity plus final visual/CI3 and original-parent acceptance are conjunctive consumers. No extra manuscript roles are imposed on a plain arithmetic report.

Source-code alignment is an evidence-bound reviewer question; AST sameness or hash matches cannot prove causal, scientific or physical equivalence. Score re-execution remains the ordinary scientific operation with its own authority, not a PDF writer side effect. Bibliography URLs and located text are presented evidence; reviewer identity/content/current source checks do not turn an automated opinion into guaranteed truth or conference acceptance. A better prose rebuttal cannot replace required new measurement/code evidence.

Primary publisher observations are retained separately, including blocked raw downloads. Native profile recipes remain adapted source. Actual official task template/permissions, TeX runtime/class/font versions, all loaded libraries, actual authored notes and genuine reviews have not been qualified in this author slot. Frontier's LangGraph coordinator chooses/invokes the published calls through stable execute_graph; the ordinary stage DAG continues to own native builds. The manuscript services neither duplicate the scheduler nor use checkpoints as scientific approval.
