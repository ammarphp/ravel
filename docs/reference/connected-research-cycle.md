# Connected research cycle

`ravel.workflow.research_cycle` connects a question and falsifiable hypotheses to ordinary source-bound studies, reviews and quantity-bound reports. It is a hypothesis/experiment/rebuttal loop. Graph and Host own calls, `science` owns approval and supervised attempts, and `physics_review` owns scientific decisions.

A campaign starts with `create`, then `propose` or `import_board` and complete `design` records. `configure_phases` reserves declared checks before construction or polish. `select` records feasible designs; prediction separation is an exploration heuristic rather than an information-gain estimator. `prepare_experiment` builds the normal scientific plan. `run_experiment` rechecks the current plan, historical parent feedback, premise applicability and phase obligations at the dispatch boundary before delegating to the existing scientific lifecycle. Source or applicability drift requires redesign.

`observe` retains failures and actual results. A missing observable remains unknown; it does not match a literal null prediction. `adjudicate` requires the real scoped review journal, and scientific acceptance remains separate from a model's completion claim. `feedback_packet` binds current evidence for revision. `adopt_revision` requires an actual charged Graph result; `adopt_source_revision` retains explicitly supplied revisions with their source origin. The Host `research-revision` action binds proposal and feedback as ordinary graph inputs under the improver role.

`import_failed_stage` consumes canonical failed-stage diagnostic evidence without upgrading its result to normal delivery or reuse. Its historical resource debit binds the retained scientific specification when a typed resource field is absent. `continue_campaign` retains the previous history under a new explicit budget and reason; it does not silently restart an expired campaign. `synthesize` delegates to the existing report constructor and retains requested-quantity missingness.

Portable engineering controls exercise real Host/Graph and ordinary harmless arithmetic workers with explicit synthetic role journals. They do not demonstrate independent model reasoning, causal improvement, native physics or an autonomous multi-iteration scientific completion. Failed prior source candidates, actual failed scientific attempts and their review findings remain preserved.

For a failed attempt already observed by this cycle, `attach_failed_stage(root, experiment_id, intake_pin)` joins a canonical diagnostic intake to that exact retained run, stage, attempt and original ordinary observation. It freshly verifies the prior result commitment and existing resource reservation, retains the observation, and adds no attempt or debit. Subsequent critique and successor design use the existing diagnostic and ordinary study APIs; attachment grants no acceptance, retry or launch authority.

Feedback and synthesis separate current measurement applicability from premise-dependent interpretation. The original comparison stays in history when an interpretation loses its premise, and it must not count as current task completion. These APIs have portable source controls; actual scientific improvement through a successor study remains a separate evaluation.

The focused `ravel research-cycle` command delegates to these same APIs; see [ordinary research commands](../guides/connected-research-commands.md). It provides no second scheduler, automatic approval or verdict. Prepared review Graph execution additionally requires the separately reviewed existing-ledger join.
