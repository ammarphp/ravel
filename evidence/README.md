# Evidence

This directory contains curated historical measurements, benchmark inputs, and
the metadata needed to check public claims. A checksum establishes file
integrity. It does not establish scientific correctness or a successful fresh
simulation.

## Registry and provenance

[collections.json](collections.json) is the single selection and relocation
registry used by the evidence checks and packaged replay. Each collection
names its original source directory and run ID, public destination, purpose,
and explicit include/exclude patterns. `*` matches within one path segment;
only `**` recurses. Unlisted source archives and event dumps do not ship.

Public copies use descriptive directory names while retaining archival
filenames, embedded original paths, and recorded failures; checks verify their
recorded source hashes.
The shared resolver finds those inputs in either layout without rewriting
benchmark registries or historical records.

[manifest.json](manifest.json) binds claims to artifact hashes and byte counts.
[claims.json](claims.json) registers the scoped values quoted in the
[results page](../docs/validation/results.md). Uncited historical claims may
refer to run records that this repository does not include; every published verified claim requires its named
evidence in the public tree.

The only record-content changes in these copies are the home-directory and
repository-URL redactions and the wording and recorded-path curations listed in
[curation.json](curation.json).
Each curation entry maps a record's original sha256 and size to its curated copy,
names the records that pinned the original digest, and says what changed
and why; numbers and data are unchanged (a curated gzip record is recompressed
deterministically around its curated member), and a check that pinned the original
digest accepts only that exact curated copy. The superseded native-fidelity-v2 verifier is the
exception: by design it rejects current sources that changed after its audit, so it no longer
passes and is not part of the publication checks (native-fidelity-v3 records the successor checks).
The provenance record (`export-provenance.json`) binds every exported path to its digest;
the evidence index (`docs/validation/evidence.md`) is generated by `scripts/build_evidence.py`,
and `DIRECTORY.md` is maintained by hand. Source revisions recorded inside audit records
name commits that are not part of this repository's history; the per-file sha256 values
identify the recorded bytes.

```bash
python3 scripts/check_evidence.py --check
python3 scripts/check_publication.py
```
