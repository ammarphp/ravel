# Shipped analysis assets: provenance note

Evidence file pinned by the reviewed records in this directory.

These records restore descriptors and source bundles that the 2026-10-10 development line
held as fixed code (the six-b trace/classifier package, the native fill-site schemas, the
slepton direct-lepton response contract, the compressed-selection cutflow). Each descriptor
binds exact source bytes by sha256, so a different byte stream is refused, never adapted.

- The descriptors transcribe source semantics (what the released routine fills, books and
  vetoes). They are not validation of the physics, of a native build, or of a response.
- Checks the bounded expression language cannot state elementwise (object ordering,
  pairing-candidate membership) are listed in each descriptor's limitations.
- The review is a software translation. Physicist review of each descriptor is still
  required; the `reviewer` field says so.
