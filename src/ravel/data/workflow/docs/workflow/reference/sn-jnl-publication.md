# Explicit current EPJC native recipe

The `epjc` formatting profile can select `render.class="sn-jnl"`. This is a separate choice from the preserved explicit `svjour3` legacy option and supplied `source-template` path. Use the actual publisher class and selected `sn-mathphys-num.bst` as full path/SHA/size `template_assets`; keep the complete distribution/licence/guide as source inputs. The [current EPJC instructions](https://link.springer.com/journal/10052/submission-guidelines) recommend the Springer Nature template with `iicol`; the [official December 2024 package](https://www.springernature.com/gp/authors/campaigns/latex-author-support) supplies the class, styles and original example.

The independently written native recipe emits `pdflatex,iicol,sn-mathphys-num`, numeric bracket references and native title-before-abstract layout. Original literal author names and affiliations become unindexed `\author` and `\affil` declarations, followed by `\abstract{...}` and `\maketitle`. This preserves every supplied string without inventing author-to-affiliation associations. The current manuscript source schema does not represent affiliation IDs, email, ORCID, corresponding-author status or author-name components; manuscripts needing these require a separately source-qualified structured schema or exact supplied source template. No generic article abstract environment or center-based affiliation substitution is used in the native branch.

Line-number requests use the original class `lineno` option and `vruler` dependency. Existing article/REVTeX/SVJour3 line-number recipes remain unchanged. Required class/style/package names are source-readiness commitments, not a dynamically complete TeX/font/loaded-ABI census. Use the existing publication runtime materializer, qualified runtime closure and ordinary `manuscript-build` workflow; no compiler, font, bibliography or TeX installation is performed by this recipe.

This code describes an independently implemented interface to the real class, not copied publisher implementation. The acquired class/style distributions retain their original notices. The distribution advertises template version 3.1 December 2024; `sn-jnl.cls` itself reports 2019/11/18 v0.1. Preserve both source facts rather than invent a unified version. The class/BST filenames alone do not establish genuine publisher origin: retain original URLs, archive bytes, licence notices, complete member manifest and journal-level instructions as evidence.

The recipe is deliberately EPJC-specific. A general Springer Nature submission template with `sn-nature` bibliography is not a Nature print-layout or final house-style certification. A task-specific publisher or collaboration template is a supplied input. Source admission, authored content, ordinary approval, actual recorder/PDF/preview lineage and independent visual/semantic/publisher review remain distinct. No journal submission or acceptance is automatic.
