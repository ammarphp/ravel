# Scoped workflow controls

The JSON files are reviewable starting prescriptions, not preapproved calculations.
See the [workflow guide](../../docs/workflow/reference/scoped-workflows.md).

- `atlas-2jl-counting.json`: published-input single-bin statistical approximation.
- `drell-yan.json`: 100-event LO parton control; replace the three native runtime paths.
- `run_controls.py`: bounded CLI integration experiment requiring explicit scripted-YES
  authorization; fresh runs and machine-readable outcomes, with native execution optional.

These controls do not rerun RRR detector samples or establish acceptance or publication readiness.
